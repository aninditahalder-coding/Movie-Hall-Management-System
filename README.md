# 🎬 Movie Hall Management System

### A Python-based Movie Ticket Booking and Management Application

A desktop application developed using **Python and PySide6**, designed to simplify movie browsing, theatre selection, seat booking, and booking management through an interactive graphical user interface.

## 📌 Project Overview

The **Movie Hall Management System** provides a user-friendly desktop interface for exploring movies, selecting theatres and showtimes, booking seats, and viewing booking information.

The project focuses on combining Python programming, GUI development, and practical booking management concepts into a single application.

## ✨ Key Features

- 🔐 **Login & Registration** — Dedicated interfaces for user login and registration.
- 🎥 **Movie Browsing** — Explore available movies through an interactive interface.
- ⭐ **Movie Details** — View movie descriptions, ratings, and cast information.
- 🏢 **Theatre Selection** — Select a preferred theatre and showtime.
- 💺 **Interactive Seat Selection** — Choose seats through a graphical seating arrangement.
- 🎟️ **Booking Confirmation** — Display booking details and ticket costs.
- 📋 **My Bookings** — View booking information through a dedicated interface.
- 👤 **User Profile** — Dedicated profile interface.
- 🎨 **Customized GUI** — Attractive layouts, styled buttons, and cinematic backgrounds.

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/aninditahalder-coding/Movie-Hall-Management-System.git
```

### 2. Open the Project Folder

```bash
cd Movie-Hall-Management-System
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install PySide6
```

### 5. Run the Application

```bash
python main.py
```

The Movie Hall Management System application should launch.
